# Sukruti & Harsha

Public welcome page for `https://sukrutiharsha.github.io`.

Publish only this directory to the public `sukrutiharsha/sukrutiharsha.github.io`
repository. Enable GitHub Pages from the `main` branch, root directory.

Set `WEDDING_GALLERY_URL` in `config.js` to the verified HTTPS address of the
password-protected app. Visitors follow the link to the app; the browser address
changes there. Keeping the interface and API together preserves the app's session
cookies and avoids cross-site login problems.

No photos, face vectors, passwords, private configuration, or backend data belong
in this repository. With no gallery URL configured, the page displays a setup
message instead of a broken link.
